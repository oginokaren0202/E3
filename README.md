# 寫法說明

## 檔案

- `setting.txt`：網站標題、簡介、角色
- `days/day01.txt`、`day02.txt`……：一天一個檔案，數字補零
- `images/`：插圖

## setting.txt

```
標題：網站標題
簡介：簡介文字

角色：
角色名 #顏色
角色名 #顏色 avatars/頭像檔名.png   ← 有頭像才加
```

## 每天的文章

```
# 當天標題                      ← 第一行

一般文字就是旁白

## 場景標題

角色名：對話內容                ← 角色名要先寫在 setting.txt

🎲 角色名 技能 23/60            ← 擲骰，自動判斷成功／失敗
🎲 角色名 技能 23/60 困難成功   ← 自訂結果文字
🎲! 角色名 技能 12/45           ← 關鍵判定（醒目顯示）

[圖] day01/檔名.jpg 圖說        ← 對應 images/day01/檔名.jpg，圖說可省略
```

- 目錄會自動列出所有天數，有 🎲 的日子自動標記
- 天數要連續，中間缺一天，後面的不會顯示
